|---|---|

| Legacy / experimental tags | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability or critical defect in this project (including CI/CD pipeline injection, kernel patch flaw, or supply-chain compromise), please report it responsibly:

- **Email**: `femmyaureliavaleriana@gmail.com`
- **Maintainer**: `@femmynuppu`

Please include:
1. Affected workflow, branch, or kernel source file.
2. Step-by-step reproduction instructions or Proof-of-Concept.
3. Potential impact on build runners, flashable artifacts, or target devices.

Do not open public GitHub issues for undisclosed security vulnerabilities. We will acknowledge reports within 48 hours and work on a prompt fix.
